# FileSeeker — macOS 本地文件搜索工具

图形化筛选 + 按 APFS 落盘时间查找的免费开源工具。纯 Swift 6 + AppKit + SQLite3 单文件实现，无第三方依赖、无网络请求、无遥测。

写它的原因：找不到一个同时满足「按文件名快查 + 图形化多选筛选 + 按落盘时间筛选 + 免费」的现成工具，于是自己写了一个。

## 功能

### 1. 按文件名快速查询
- 搜索框输入关键字，回车查询；支持中文、英文、部分匹配。
- 查询在后台线程执行，界面不冻结；连续输入时用序号丢弃过期结果，不会旧结果覆盖新结果。

### 2. 图形化筛选（下拉框 / 复选框 / 日期选择器，不用记搜索语法）
| 筛选项 | 控件 | 说明 |
|---|---|---|
| 搜索范围 | 下拉框 | 用户目录 / 启动磁盘全部文件 |
| 文件类型 | 下拉框 | 全部、文档、图片、视频、音频、压缩包、代码、字体、其他、文件夹 |
| 扩展名 | 多选面板 | 9 组 28 个常用格式，点组名整组勾选；可手动补充任意格式 |
| 大小 | 下拉框 + 输入框 | 预设 `>1MB / >10MB / >100MB / >1GB`，或自定义最小 / 最大 MB 区间 |
| 落盘时间 | 日期下拉 + 起止选择器 | 按 APFS 创建时间（`birth`，即真实落盘时间）区间筛选 |
| 修改时间 | 日期下拉 + 起止选择器 | 按 `mtime` 区间筛选 |

扩展名分组：Word 文档（doc/docx/wps）、表格（xls/xlsx/et/csv）、演示文稿（ppt/pptx/dps）、PDF/文本（pdf/txt/md/rtf）、图片、视频、音频、压缩包、代码。Word 组含 doc、docx、wps 三种。

### 3. 结果表格与操作
- 六列：名称、类型、大小、落盘时间、修改时间、完整路径。
- 点表头按任意列排序，可切换升降序；默认按落盘时间倒序。
- 双击打开文件；右键菜单：打开、在 Finder 中显示、复制完整路径、快速查看（选中按空格）。
- 字号滑块 10–22pt 实时调整表格字号。
- 状态栏显示命中数与截断提示（上限 20000 条）。

### 4. 菜单栏常驻
- 无 Dock 图标、不参与 Cmd+Tab；只在状态栏显示放大镜图标。
- 左键点击图标显示 / 隐藏窗口；右键菜单：显示 / 隐藏、开机自启动开关、退出。
- 开机自启使用系统原生 `SMAppService.mainApp.register()`，不依赖 LaunchAgent。
- 窗口关闭只隐藏不退出，进程常驻菜单栏。

### 5. 自建索引
- 点「重建索引」扫描用户目录或整块启动磁盘，自动跳过 `/System`、`/private`、`/dev`、`/usr` 等系统卷。
- 索引字段：路径、名称、扩展名、类型、大小、落盘时间、修改时间、是否目录。
- 索引库位于 `~/Library/Application Support/FileSeeker/index.db`，纯本地，仓库不含任何索引数据。

## 性能

95.5 万行索引下，关键字查询约 120–135 ms，无关键字浏览最新文件约 28 ms。

优化手段：预存小写冗余列 `name_lc` 避免 `COLLATE NOCASE` 逐字符折叠；有关键字时去掉触发优化器误选索引的 `ORDER BY`，改在 Swift 侧内存排序；查询在后台队列执行。

## 构建

需要 macOS 13+ 与 Swift 6（Xcode Command Line Tools 即可，无需完整 Xcode）：

```bash
git clone https://github.com/Leeeeeeee-1/FileSeeker-macOS-GUI-File-Search.git
cd FileSeeker-macOS-GUI-File-Search
chmod +x build.sh
./build.sh
```

`build.sh` 会编译 `main.swift`、组装 `.app`、ad-hoc 签名，产物在 `dist/FileSeeker.app`，拖进 `/Applications` 即可。

也可以只编译二进制：

```bash
swiftc -O main.swift -o fileseeker
```

## 自检

内置隐藏自检分支，验证索引、查询、扩展名面板构建与整组勾选，不进入 GUI 事件循环：

```bash
./fileseeker --selftest
```

## 首次使用

启动后点「重建索引」扫描用户目录（约 95 万文件需几分钟）；索引完成后输入文件名查询。右键菜单栏图标可开启「开机自启动」。

## 已知限制

- 静态索引：新文件需手动点「重建索引」，不含 FSEvents 实时增量。
- 索引库含完整路径，属本地敏感数据；仓库不包含任何索引文件。
- 全盘扫描需要「完全磁盘访问」权限，用户目录扫描一般不需要。
- 结果上限 20000 条，超出会提示细化条件。
- 窗口关闭后进程常驻菜单栏，这是预期行为。
